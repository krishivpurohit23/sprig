# sprig

campus care web app — [sprig-gold.vercel.app](https://vercel.app)

## about
A simple web app to help students stay on top of campus care, updates, and resources without digging through multiple portals. Built with vanilla JS and Vite to keep things fast and lightweight.

## tech
- HTML / CSS / JavaScript
- Vite
- Vercel

## local setup

```bash
git clone https://github.com
cd sprig
npm install
npm run dev
```

## files
- `index.html` — main page
- `app.js` — main logic & UI rendering
- `data.js` — campus data
- `intelligence.js` — recommendations / logic
- `components/` — UI components
- `assets/` — images & icons
